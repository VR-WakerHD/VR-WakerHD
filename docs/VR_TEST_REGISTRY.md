# VR test registry

The tests run in the Forsaken Fortress test environment ([VR_TEST_ENVIRONMENT.md](VR_TEST_ENVIRONMENT.md)), one at a
time. Where testing stands, and the next action, is in [VR_TEST_PROGRESS.md](VR_TEST_PROGRESS.md).

**Statuses:** `NOT_STARTED`, `IMPLEMENTED_NEEDS_BUILD`, `READY_FOR_MANUAL_TEST`, `IN_MANUAL_TEST`, `ISSUES_FOUND`,
`AWAITING_USER_CONFIRMATION`, `CONFIRMED_PASS`, `COMMITTED`.

**The rules:**
- A test is `CONFIRMED_PASS` only on the tester's explicit statement that it passes and all its issues are closed. A
  build, automated tests, or the agent's view are not enough.
- Only then are that test's changes committed, its commit recorded, and the next test started.
- Stage 2 starts only after Stage 1 is confirmed complete and committed; Stage 3 likewise after Stage 2.

**Setup for every Stage 1 test:**
- `vr.leftHanded=0` (right-handed: F1 > VR "Left-handed" off).
- In the test environment, freshly reset (F1 > VR > Reset).
- Put the item under test on a button with the item wheel (off-hand over the shoulder), unless the test says
  otherwise.

## Stage 2: left-hand mode

Every Stage 1 test again with `vr.leftHanded=1`, the left controller holding the items. IDs L-ENV-01 … L-ITM-08,
mirroring the R- tests. These start only after Stage 1 is confirmed and committed. The extra checks are:
- no residual right-hand attachment;
- the swing direction and the side swing's side are mirrored correctly;
- the laser starts from the left hand.

Status: `CONFIRMED_PASS` (2026-10-26, the tester: "ok we are good commit all changes to right hand and left hand modes and all changes to the menu"), committed with the item wheel changes as 83748aab. Setup: `vr.leftHanded=1`.

As asked for (I-24): the bow, hookshot and grappling hook are set up exactly as in right-handed play: the bow in the
right hand, the hookshot and grappling hook in the left, the same triggers. The sword, shield, hammer and boomerang
follow the handedness; the boomerang too is set up as in right-handed play (I-25): in the left hand, aimed from it,
thrown by the left trigger or a downward swing of the left hand.
