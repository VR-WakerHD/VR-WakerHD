Wind Waker VR on Linux

Linux is VR-WakerHD's main development platform (Arch Linux / CachyOS). The Linux release is an AppImage for x86-64 PCs, and there is a separate arm64 AppImage for the Steam Frame.

Requirements

  • x86-64 Linux with glibc 2.35 or newer: Arch / CachyOS, Fedora 36+, Ubuntu 22.04+, Debian 12+.
  • A Vulkan GPU driver, and an OpenXR runtime: SteamVR or Monado (both tested), or WiVRn (supported, little testing).
  • The packages for your distribution listed in required_packages.txt in the release.

Install and run

  1. Download VR-WakerHD-Linux-0.6.0-x86_64.AppImage from the latest release.
  2. chmod +x VR-WakerHD-Linux-0.6.0-x86_64.AppImage and run it.
  3. Choose your own game files; setup compiles the game for your PC (once).
  4. Start SteamVR or Monado, make it the active OpenXR runtime, and press Play VR.

Runtimes on Linux

  • SteamVR: tested, and plays smoothly most of the time; occasional pacing dips from SteamVR on Linux are being worked on.
  • Monado: tested with a PS VR2 headset.
  • WiVRn: supported, little testing.

Steam Frame (SteamOS, arm64)

VR-WakerHD-SteamOS-aarch64-0.6.0.AppImage is built, with Quest-like tuning, but not yet confirmed on the device.

Troubleshooting

  • It doesn't start: install the packages in required_packages.txt.
  • VR doesn't start: an OpenXR runtime must be active; the log's [vr] lines say why.
  • Log file: ~/.local/share/wwhd/captures/wwhd.log (the previous start's is wwhd-previous.log); attach it to a bug report.
