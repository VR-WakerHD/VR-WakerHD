How to install the Wind Waker HD VR mod

From a release download to playing in your headset, on Windows, Linux, SteamOS and Meta Quest 3 / 3S. You need your own copy of the Wii U game; nothing from the game is in the download.

What you need

  • Your own copy of the Wii U game, dumped from your own disc and console: a .wud / .wux disc image with its disc key and the Wii U common key, a Cemu .wua archive, or an extracted game folder (holding code, content and meta).
  • For PC VR: a Vulkan-capable GPU and an active OpenXR runtime (SteamVR, Meta Quest Link, Virtual Desktop, Windows Mixed Reality, or Monado / WiVRn on Linux).
  • For Quest standalone: a Meta Quest 3 or 3S in developer mode.

The USA version of the game is tested most in VR; the European version is supported by the base port.

2. Start it

  • Windows: unzip into a folder of its own (for example C:\Games\VR-WakerHD) and start wind-waker-hd-vr.exe.
  • Linux / SteamOS: chmod +x VR-WakerHD-*.AppImage and run it; if it doesn't start, install the packages in required_packages.txt. More: Linux guide.
  • Quest 3 / 3S: install the APK with SideQuest or adb install, then open it from Unknown sources. More: Quest 3 guide.

3. Set up the game (once)

The installer opens on the first start. Choose your game files; setup extracts the game if needed and compiles it for your device: a few minutes on a PC, longer on a headset. What setup makes stays on your device and must not be shared.

4. Play

  1. On PC, start your OpenXR runtime first and make it the active one (SteamVR: Settings > OpenXR > "Set SteamVR as OpenXR runtime").
  2. In the VR launcher, check the headset, refresh rate, controls and graphics.
  3. Press Play VR, or Play Flat to play on the monitor.

In the headset, click the left stick for the settings menu. How to play: controls. Problems: FAQ and troubleshooting.
