Wind Waker PC VR: SteamVR, OpenXR and Quest Link

On PC, VR-WakerHD uses OpenXR with the Vulkan renderer, so any headset with an OpenXR runtime that supports Vulkan (XR_KHR_vulkan_enable2) should work. "Tested" means played in a headset by the developer or testers; "supported" means it should work but has had little testing.

Headsets

Tested most: PlayStation VR2 (SteamVR, Monado) and Meta Quest 3 / 3S (Link). Supported: Valve Index, HTC Vive, Windows Mixed Reality headsets, and other OpenXR headsets through the standard controller profiles.

PC requirements

  • A GPU with a Vulkan driver: Vulkan 1.3, or 1.1 / 1.2 with VK_KHR_dynamic_rendering.
  • Windows x86-64 or Linux x86-64. macOS has no VR build (VR needs the Vulkan renderer).
  • Performance depends on the scene and the headset resolution; the render thread (CPU) usually sets the limit more than the GPU.

Set up

  1. Install your runtime and make it the active OpenXR runtime (SteamVR: Settings > OpenXR).
  2. Download the Windows zip or the Linux AppImage and run setup once with your own game files (install guide).
  3. Start the runtime first, then press Play VR in the launcher.
