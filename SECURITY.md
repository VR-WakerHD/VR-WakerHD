# Security policy

VR-WakerHD is a fan project maintained by a small team. Security fixes go into the latest release only.

## Reporting a vulnerability

Please don't open a public issue with the details. Use GitHub's private reporting, the **Report a vulnerability**
button on the repository's [Security tab](https://github.com/VR-WakerHD/VR-WakerHD/security), if it is shown there.
If it isn't, open an [issue](https://github.com/VR-WakerHD/VR-WakerHD/issues/new/choose) asking for a private contact,
without the details.

Useful to include: the version, the platform, what an attacker could do, and the steps to reproduce it.

## Scope

The VR mode, the VR launcher, setup and the release files. Problems in the base port belong to
[ZeldaWWHDRecomp](https://github.com/ZeldaWWHDRecomp/ZeldaWWHDRecomp); problems in an OpenXR runtime belong to its
makers.
